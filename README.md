# EDA Play Store Analysis 

## Project Overview
This project performs Exploratory Data Analysis (EDA) and data preprocessing on Google Play Store dataset and visualization on Honey Production dataset.

## Objectives
- Clean and preprocess raw data
- Handle missing values and duplicates
- Perform feature engineering
- Visualize data using Matplotlib and Seaborn
- Prepare dataset for future machine learning models

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Steps
- Data cleaning (Size, Installs, Price, Reviews)
- Created Rating_Category (High/Low)
- Encoding categorical variables
- Train-test split
- Standardization
- Data visualization (pie, scatter, boxplot, pairplot, heatmap)
